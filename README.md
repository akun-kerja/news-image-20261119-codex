# The World Ledger — 19 November 2026

A one-page illustrated newspaper front page summarizing six supplied world-news stories from Thursday, 19 November 2026. It is drawn from shapes and typography, with the International Court of Justice ruling on Myanmar and the Rohingya as the lead.

## The six stories

1. **World Court:** The ICJ rules Myanmar committed genocide against the Rohingya, the first such ruling against a State. Gambia brought the case in 2019.
2. **Shenzhen summit:** Donald Trump, Vladimir Putin and Xi Jinping meet on the sidelines of APEC, issue a four-point Declaration toward Peace, and focus on Ukraine.
3. **Bangladesh:** Muhammad Yunus's ancestral home is set on fire and four people are killed amid unrest in 28 districts.
4. **Gaza:** Israeli forces cross the ceasefire line in a ground operation in Nuseirat despite the truce; aid groups rate peace-plan implementation 4 out of 26.
5. **Climate and energy:** COP31 ministers work to unblock negotiations and adopt a final text; the IEA warns the Hormuz crisis is the greatest energy-security threat it has observed.
6. **Money:** A Van Gogh painting sells for a record $190.4 million; Anthropic raises about $81 billion in a record-setting IPO.

## Run

Generate the 1024×1024 PNG with Python 3 and Pillow:

```sh
python3 draw_image.py
```

Copy the generated image into the make.fun output directory with Node 22:

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` may be set to choose another destination. It defaults to `/output`.
